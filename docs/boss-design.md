# 第一张图关底 Boss 设计

> 状态：方案已确认（3 阶段 + 肩部导弹齐射）。归入 **D 路第二波**（与加特林/火箭弹武器一起实现）。
> 关联：`docs/weapon-drop.md`（武器掉落）、`docs/game-design.md`（D 路多阶段流程）、`docs/ai-design.md`（B 路护盾精英机制）、`docs/MIGRATION.md` §多 agent 并行分工（C 路垂直空间）。

## 1. 定位

**身份：重装四足机甲守卫**——机械猎犬（hound）的「终极体」，比 hound 大 3~4 倍，玄鲸港区中继的守门人。

选它作为第一张图关底的理由：
- 与现有 hound 有血缘关系，主题统一（不是凭空塞怪物）；
- 承接 B 路在做的「护盾精英 + 远程压制」机制，boss = 精英的集大成；
- 利用 C 路的垂直空间做登场舞台（从集装箱堆之间撞出来、爬上门架）。

## 2. 出现时机

第一张图流程 = **潜入 → 断 3 处中继 → boss 战 → 撤离通道打开 → 进图 2**。boss 是图 1 关底，打赢才解锁图 2。

节奏设计：
- 断第 2 处中继 → **警报升级**（红光、广播、gull 群开始集结，先给压迫感）；
- 断第 3 处中继 → **boss 现身**（完成主线目标不是结束，而是触发关底战）。

## 3. 三阶段结构（血量阈值触发）

| 阶段 | 血量 | 形态 | 打法主题 |
|---|---|---|---|
| Phase 1「重装·完好」 | 100%→66% | 装甲完整、行动稳重 | 学节奏、躲弹幕 |
| Phase 2「破甲·暴露」 | 66%→33% | 背甲弹开、核心裸露 | 抓弱点窗口、边打边躲群 |
| Phase 3「过载·濒死」 | 33%→0 | 散热片全开、红光、冒烟 | 狂暴弹幕里拼集火 |

## 4. 每阶段攻击方式

### Phase 1（给玩家学习空间，攻击慢、前摇明显）
1. **蓄力冲锋**——前足刨地约 0.8s 后直线冲撞，撞到掩体顿一下（破绽）。
2. **扇形扫射**——正面 120° 弹幕，逼玩家绕侧或躲掩体，别站正面。
3. **踏地震波**——前足砸地，一道地面冲击波推过来，跳过去即可。

### Phase 2（更激进 + 会摇人）
1. **召唤 gull 群**——呼叫机械飞鸥骚扰，分散火力。
2. **肩部导弹齐射**——从肩部发射追踪弹（敌方版火箭弹，与第二波玩家火箭弹共用弹道系统）。
3. **强化冲锋**——更快、可中途转向；冲锋后约 1.5s 背部核心短暂暴露（**本阶段唯一高伤窗口**）。

### Phase 3（濒死狂暴 + 垂死反扑）
1. **全弹发射**——所有武器同时开火，弹幕地狱。
2. **过载 AOE**——每隔几秒核心蓄能，周围大范围爆炸（逼玩家拉开距离）。
3. **间歇瘫痪**——每次过载 AOE 后停摆 2~3s（集火窗口）。移动变慢，火力频率暴涨，经典「濒死才最危险」。

## 5. 战损 / 变形节点

**两个硬变形点**（血量阈值触发，带演出）：
- **66% 破甲**：背甲「砰」地弹开、火花四溅 → 核心裸露。机制转折：核心成为高伤弱点（打核心伤害翻倍），同时进入 Phase 2 招式。
- **33% 过载**：散热片展开、机体泛红光、浓烟滚滚 → 「过载形态」。视觉上「要炸了」，机制上火力全开但开始间歇瘫痪。

**渐进战损**（不用到阈值才变，持续给反馈）：装甲板逐块剥落 → 关节火花 → 冒烟 → 一瘸一拐。玩家扫一眼就知道「还剩多少血」。

## 6. 转阶段演出

转阶段时：boss 停顿 1~2s + 变形动画 + **无敌帧**（期间打它不掉血），避免玩家在变形时白打、或被转阶段瞬间的攻击阴到。这是「战损」观感最强的时刻。

## 7. 掉落与撤离

- **掉落：加特林**（呼应「精英掉重型武器」，加特林归 D 路第二波）。
- **打开撤离通道** → 进入第二张图（承接 D 路 `extract` 阶段：全切中继后本应直接撤离，现改为先打 boss 再放行）。

## 9. 依赖与契约（待契约 PR 确认）

- **实体类型**：boss 需新 EntityKind（建议 `sentinel`，或复用 B 路提出的 `elite` 变体体系做顶级版）——与 B 路的 `suppressor|elite|env` 扩展一起定。
- **追踪弹道**：肩部导弹齐射引入追踪弹，需新增弹道/AOE 伤害路径（现有 combat 是单体 hitscan）。
- **boss 战事件**：建议新增 `boss:spawn` / `boss:phase` / `boss:killed`，供 HUD（血条）、音频、阶段切换订阅。
